# 🎥 Анализ Поведения Пользователей YouTube через Кластеризацию Видео

![youtube](https://i.pinimg.com/originals/72/ad/d6/72add67ff9f5065095af6d8eb1e81f79.jpg)

## 📋 Описание проекта:
В данном проекте я провел анализ сегментации клиентов по ключевому слову **data analyst**, используя данные, полученные через **YouTube API**. Основной целью было понять различные группы видео на YouTube и выделить ключевые характеристики каждой из этих групп.

Проект включает в себя следующие этапы:

1. **📊 Сбор данных**: Я использовал **YouTube API** для получения данных о видео (идентификатор, название, канал, дата публикации, описание и URL миниатюр).
2. **🛠️ Подготовка данных**: Очищенные данные были преобразованы в таблицы с использованием библиотеки `pandas` для удобного анализа.
3. **🔍 Сегментация видео**: Применив метод **K-средних (K-means)**, я сегментировал данные по просмотрам, лайкам и комментариям.
4. **📈 Визуализация и интерпретация**: Результаты кластеризации визуализированы, что позволило выявить ключевые особенности каждой группы видео.

## 🔧 Используемые библиотеки:

## 🚀 Этапы проекта:

### 1️⃣ Сбор данных
С помощью YouTube API были получены данные по ключевому слову **data analyst**. Извлеченные данные включают идентификаторы видео, названия, каналы, даты публикации, описания и URL миниатюр.

### 2️⃣ Подготовка данных
После получения данных они были очищены и преобразованы в удобный для работы формат. Для этого я использовал библиотеку `pandas`, что позволило гибко управлять и анализировать данные.

### 3️⃣ Кластеризация видео
Для сегментации видео по метрикам просмотров, лайков и комментариев был применен метод **K-средних**. В процессе я стандартизировал данные с помощью `StandardScaler`, а также уменьшил их размерность через **PCA** для лучшей интерпретации.

### 4️⃣ Визуализация данных
Полученные кластеры были визуализированы с использованием **matplotlib** и **seaborn**, что помогло наглядно увидеть различия между группами видео.

## 💡 Выводы:
Этот анализ позволяет лучше понять, как различный контент привлекает пользователей YouTube, а также помогает выделить популярные категории и улучшить стратегии создания контента.
